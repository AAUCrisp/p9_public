# p9
P9 - Client Side Streaming Performance Monitoring

### OBS!
*DR1 Dash* and *HLS* buttons, only show functioning *DASH* and *HLS* streaming. 
They're delivered by *Norlys* servers, so the performance data is **not** being picked up for the projects backend to process.





## Backend is on Backend Branch
The backend is on the *Backend* branch on this *git*.

### Own Backend Testing
Enter the *app/src/main/java/com/crisp/streamperformance/MainContent.kt* and enter your URL to the *DASH* or *HLS* manifest from your own backend, in the *serverUrl* variable around line 50.
